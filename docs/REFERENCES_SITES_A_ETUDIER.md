# Références à étudier sans copier

- OM officiel : actus, communiqués, conférences, effectif. OFFICIEL seulement si club/source fiable.
- Ligue 1 officiel : calendrier, classement, résultats.
- OneFootball : combinaison live scores + stats + news + vidéos.
- Flashscore/Livesport : score instantané, onglets match, statistiques, notifications.
- Sofascore : stats détaillées, notes joueurs, heatmaps/shotmaps quand data disponible.
- FotMob/Forza Football : timeline claire, fiches match, notifications.
- Betclic : observer seulement l’idée du mini-terrain, ne pas copier le design.
- GitHub : chercher idées techniques générales (PWA sports dashboard, SVG pitch, service worker, RSS backend) et vérifier les licences.
